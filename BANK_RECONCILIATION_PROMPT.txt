Amazon Refund Ledger bank reconciliation request

Upload the exported `amazon-refund-credit-check-YYYY-MM-DD.json` file to ChatGPT and send:

Reconcile every return in this Amazon Refund Ledger bank-credit-check request against my connected Finances accounts.

Matching rules:
- Use posted credits for confirmation; pending transactions may be reported as pending but must not be confirmed.
- Prefer exact refund amount, matching payment-card last four when available, Amazon/Amazon Marketplace merchant evidence, and a plausible posting date after the refund-issued date.
- Do not reuse one bank credit for multiple return records unless the transaction clearly represents a combined refund and explain the grouping.
- If no exact/strong posted match exists, return `pending` or `not_found`; do not guess.
- If multiple plausible credits exist, return `ambiguous`.
- Return a downloadable JSON with schema `amazon-refund-credit-check-result/v1`, echo the same requestId, and include one match per returnRecordId.

Do not include bank credentials, account numbers beyond last four, or unrelated transactions in the result.
